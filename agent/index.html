WHAT IT DOES

不是“自动乱写”，而是一条受控生产线

Agent 负责分析和生成，人负责关键判断。缺少价格、规格、材质时可以继续分析，但这些未经确认的事实绝不会进入正文。

01

证据分析

从参考文案提取用户、场景、痛点、动作和内容结构，每项分析保留参考依据。

02

事实隔离

产品客观事实与 Agent 推断建议分栏输出，同行资料不能替代当前产品资料。

03

两次确认

第一次确认分析和选题，第二次确认最终文案；没有确认就不继续、不写飞书。

04

完整交付

标题、250—300字正文、核心关键词、#话题标签和质量结果一次性输出。

OUTPUT STANDARD

每篇成稿都有明确验收线

标题14—18字硬性不超过20字
正文250—300字通常约280字，3—4段
完整性4项同批输出标题、正文、关键词、话题
相似度≤ 30%分别对比每篇参考正文
最终质量门7 / 7
  • 产品事实只用已确认资料
  • 标题长度14—18字
  • 正文字数250—300字
  • 内容结构场景→痛点→动作→结果
  • 话题完整包含#话题标签
  • 语言合规无虚构体验与夸张承诺
  • 文字相似度不超过30%

CAPABILITY BOUNDARIES

它能做什么，也明确不做什么

公开页面只展示能力，不开放调用。真正的生产 Agent、飞书权限和业务数据始终留在私有环境。

✓ 可以完成

  • 读取、去重10篇参考文案
  • 分析用户、场景、痛点和内容方向
  • 提出有依据的候选卖点与选题
  • 生成完整文案并执行质量检查
  • 经确认后受控写入飞书

× 不会完成

  • 用同行资料冒充当前产品事实
  • 凭空确认价格、规格、材质或效果
  • 自动选品、定价或承诺爆款
  • 未经确认直接写飞书或发布小红书
  • 向公开访问者开放真实调用

! 必须人工介入

  • 产品无法识别或客观资料冲突
  • 第一轮分析与选题确认
  • 第二轮最终内容确认
  • 事实、合规或相似度无法可靠判断
  • 飞书权限不足或写入状态不明
