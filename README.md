# Olivia qiang 个人品牌网页

这是一个静态个人介绍网页，核心定位是：

- 个人品牌，而不是传统简历
- 气质：理性怪才
- 主题：自我成长、现实决策、长期主义、人生复利
- 首屏视觉：从混乱到清晰的路线图

## 本地预览

直接用浏览器打开 `index.html` 即可。

## 当前最终版内容

- 页面姓名已使用 `Olivia qiang`
- 邮箱暂不展示
- 社交主页链接暂不展示
- 联系区文案已调整为适合通过微信转发给朋友观看的版本

## 微信分享

微信里需要分享一个公网链接，不能直接分享本地文件路径。完成页面后，可以部署到：

- GitHub Pages
- Vercel
- Netlify
- 你自己的服务器或域名
